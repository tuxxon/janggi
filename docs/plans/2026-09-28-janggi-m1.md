# Janggi M1 Implementation Plan

**Goal:** Implement the already approved M1 state machine, canonical records, resilient local storage, and controller UI.

**Architecture:** `game.js` contains immutable transitions over the unchanged rules engine. `record.js` derives positions and undo history from canonical moves. `storage.js` owns timestamps/IDs and browser I/O; React owns engine timers and animation.

**Tech Stack:** React 19, Vite, Vitest, Playwright; no new dependencies.
